# Matrix-out-of-layers-CEP-8
Plugin for creating a matrix out of layers in specific versions of Photoshop

# Установка: 
1) Нажать Win + R
2) Ввести %appdata% и нажать Enter(или кнопку "ОК")
3) Перейти в Adobe -> CEP -> extensions
4) Распаковать туда архив(или переместить папку Matrix)

# Использование
1) Создать в документе Photoshop папку Matrix
2) В папку Matrix переместить слои, из которых потом будет формироваться матрица
3) В Photoshop выбрать Окно -> Расширения -> Наш плагин
4) Выбрать размер NxM и вписать его в окно плагина
5) Нажать сгенерировать
